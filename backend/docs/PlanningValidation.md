# ArcCraft Planning Validation Specification

## Overview
Every plan generated by `CognitivePlanner` passes through `PlanValidator` to guarantee structural integrity, cycle-free task dependencies, and constraint safety.

## Validation Pipeline
1. **Goal Check**: Verifies non-null `InvestigationGoal`. Raises `MissingGoalError` if absent.
2. **Constraint Enforcement**: Verifies task count does not exceed `PlanningConstraints.max_tasks`. Raises `ConstraintViolationError` if violated.
3. **Duplicate Identification**: Ensures all `task_id`s are unique across the plan.
4. **Capability Completeness**: Validates that all tasks specify valid `TaskCapability` enums.
5. **Dependency Cycle Detection & Topological Sort**: Runs Kahn's Algorithm on task dependency graph.
   - Detects missing dependency references (`InvalidPlanError`).
   - Detects circular dependencies (`CircularDependencyError`).
   - Populates resolved `execution_order` on success.
